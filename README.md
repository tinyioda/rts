# RTS: 3D Real-Time Strategy (Unity, C#)

This repository defines a 3D RTS game built with **Unity** and **C#**.

## Core Direction
- Fully 3D battlefield gameplay with strategic unit control, base management, and resource competition.
- Systems and architecture are intended for Unity-first development using C# gameplay scripts.

## Unique RTS Features
To differentiate this game from traditional RTS designs, the project targets:
- **Temporal Command Queueing**: players can schedule commands against future timeline windows instead of issuing only immediate actions.
- **Asymmetric Information Sculpting**: terrain and structures dynamically reshape line-of-sight and sensor fidelity in real time.
- **Adaptive Objective Layer**: match objectives evolve based on player strategy patterns, creating emergent win conditions mid-match.
